# 武大美食地图 — 项目设计文档

## 1. 项目概述

**项目名称**：武大美食地图 (WHU Food Map)

**项目目标**：为武汉大学师生及周边游客提供一张交互式美食地图，展示武大周边 5 条核心美食街的推荐店铺。用户可以在地图上直观地浏览店铺位置，查看详细信息，并根据街道、菜系等条件进行筛选。

**目标用户**：
- 武大在校师生 — 日常觅食参考
- 新生/游客 — 快速了解周边美食分布
- 美食爱好者 — 按菜系、预算探索新店

**覆盖范围**：以武汉大学本部为中心的 5 条美食街。

## 2. 功能列表

### P0 — 核心功能（首版必须实现）

| 序号 | 功能 | 说明 |
|------|------|------|
| P0-1 | 地图展示 | 使用 Leaflet 加载 OSM 地图，默认定位到武大中心区域，展示 5 条美食街的覆盖范围 |
| P0-2 | 店铺标记 | 在地图上以 Marker 形式展示所有店铺，不同街道使用不同颜色标记 |
| P0-3 | 店铺列表 | 右侧面板展示全部店铺卡片，卡片包含名称、街道标签、菜系、人均消费 |
| P0-4 | 地图联动 | 点击列表中的店铺 → 地图自动飞至对应 Marker 并弹出 Popup 详细信息 |
| P0-5 | 店铺详情弹窗 | 点击地图 Marker 弹出 Popup，展示：名称、菜系、招牌菜、人均消费、简短描述 |
| P0-6 | 街道筛选 | 按美食街筛选店铺（顶部 Tab 或下拉），地图和列表同步过滤 |
| P0-7 | 响应式布局 | 桌面端：左地图右列表；移动端：地图在上、列表在下可滚动 |

### P1 — 增强功能（后续迭代）

| 序号 | 功能 | 说明 |
|------|------|------|
| P1-1 | 菜系筛选 | 在街道筛选基础上叠加菜系筛选（中餐/西餐/小吃/火锅等） |
| P1-2 | 价格排序 | 按人均消费升序/降序排列店铺列表 |
| P1-3 | 搜索功能 | 支持按店铺名称、招牌菜关键词搜索 |
| P1-4 | 收藏功能 | 用户可收藏店铺，localStorage 持久化，支持查看收藏列表 |
| P1-5 | 街道热力展示 | 地图上展示各街道的店铺密集度热力图 |
| P1-6 | 店铺详情页 | 点击进入独立详情页，展示更多图片、营业时间、用户评价等 |
| P1-7 | 路线规划 | 点击店铺后可调起地图导航（跳转高德/百度地图） |
| P1-8 | 暗色模式 | 支持明/暗主题切换 |

## 3. 技术栈选择及理由

| 层级 | 技术 | 版本要求 | 选择理由 |
|------|------|----------|----------|
| 构建工具 | **Vite** | ^5.x | 极快的冷启动和 HMR，原生支持 TypeScript 和 JSX，社区活跃 |
| UI 框架 | **React** | ^18.x | 生态丰富，组件化开发效率高，状态管理灵活 |
| 类型系统 | **TypeScript** | ^5.x | 类型安全，减少运行时错误，提升代码可维护性 |
| 地图组件 | **Leaflet** + **react-leaflet** | Leaflet ^1.9.x / react-leaflet ^4.x | 轻量（~42KB gzip），开源免费无需 API Key，插件丰富，满足标记/弹窗需求 |
| 地图底图 | **OpenStreetMap** | — | 免费开源，全球覆盖，与 Leaflet 无缝集成 |
| 样式方案 | **CSS Modules** 或 **Tailwind CSS** | — | CSS Modules 零运行时开销；Tailwind 可快速出样式（二选一，首版建议 CSS Modules 简化依赖） |
| 图标库 | **Lucide React** | ^0.x | 轻量、Tree-shakable、图标齐全 |
| 部署 | **GitHub Pages** / **Vercel** | — | 均为免费方案，静态站点部署简单，自动 CI/CD |

**为什么不选其他方案：**
- **高德/百度地图** → 需 API Key 和实名认证，Leaflet + OSM 完全免费零门槛
- **Mapbox/Google Maps** → 需要注册付费（超出免费额度后），对校园小项目过重
- **Vue** → 同样优秀，但团队成员更熟悉 React 的场景下优先 React

## 4. 数据模型设计

```typescript
// ===== 枚举类型 =====

/** 美食街标识 */
type StreetId = 'guangbalu' | 'bayilu' | 'donghuxincun' | 'luoshibeilu' | 'weilaicheng';

/** 菜系分类 */
type CuisineCategory =
  | '中餐'
  | '火锅'
  | '小吃'
  | '烧烤'
  | '面食'
  | '日料'
  | '韩料'
  | '西餐'
  | '甜品饮品'
  | '其他';

// ===== 核心数据模型 =====

/** 美食街信息 */
interface Street {
  id: StreetId;
  name: string;           // 如 "广八路"
  description: string;    // 简短介绍
  centerLatLng: [number, number];  // 街道中心坐标
  color: string;          // 该街道 Marker 的主题色（hex）
}

/** 店铺信息 */
interface Restaurant {
  id: string;             // 唯一标识，如 "guangbalu-001"
  name: string;           // 店铺名称
  streetId: StreetId;     // 所属街道
  cuisine: CuisineCategory; // 菜系
  signatureDish: string;  // 招牌菜
  avgPrice: number;       // 人均消费（元）
  description: string;    // 简短描述（50字以内）
  latLng: [number, number]; // 经纬度坐标
  tags: string[];         // 额外标签，如 ["深夜营业", "有包厢", "排队王"]
}

// ===== 视图状态模型 =====

/** 全局筛选状态 */
interface FilterState {
  selectedStreet: StreetId | 'all';  // 当前选中街道，'all' 表示全部
  selectedCuisine: CuisineCategory | 'all';  // 菜系筛选（P1）
  sortBy: 'default' | 'price-asc' | 'price-desc'; // 排序方式（P1）
  searchKeyword: string;  // 搜索关键词（P1）
}

/** 地图视图状态 */
interface MapViewState {
  center: [number, number];  // 当前地图中心
  zoom: number;              // 当前缩放级别
  activeRestaurantId: string | null;  // 当前高亮的店铺 ID
}

// ===== 店铺数据示例 =====
// 每条街暂定 6-8 家店，总计约 35-40 家店铺

const DEMO_RESTAURANTS: Restaurant[] = [
  {
    id: 'guangbalu-001',
    name: '川味居',
    streetId: 'guangbalu',
    cuisine: '中餐',
    signatureDish: '水煮肉片',
    avgPrice: 35,
    description: '正宗川菜，麻辣鲜香，学生党聚餐首选',
    latLng: [30.5350, 114.3600],
    tags: ['性价比高', '适合聚餐'],
  },
  // ... 更多店铺数据
];
```

## 7. 里程碑规划
